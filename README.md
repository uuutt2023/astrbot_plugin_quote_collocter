# AstrBot 群u语录插件
什么？群友又爆典了！当然是截图保存让他名垂千古口牙（

## 使用方法
发送“语录投稿+图片”，bot会将群u语录保存到本地（不同群聊相互隔离）  
如果你的qq未开启半屏相册发图功能，可以通过【qq左划→设置→通用→图片、视频→发图方式】进行修改  
权限系统可以通过发送“投稿权限+模式数字”进行设置  
   0：关闭投稿系统  
   1：仅管理员可投稿  
   2：全体成员均可投稿  
   
在bot被戳一戳时，将会随机选择一张黑历史发送（有10秒默认冷却，发送概率默认85%）  
如果想要修改这个冷却，请发送“戳戳冷却+冷却时间”来设置，单位为秒  
如果想要修改发送语录的概率，请发送“戳戳概率+数字”设置0.0~1.0之间的小数（1.0=必定发送，0.0=从不发送）  

## 版本更新v1.4
管理员权限获取方式优化：
移除了硬编码读取 data/cmd_config.json 的方式。
改为使用 AstrBot 标准接口 context.get_config().get("admins_id") 直接从配置文件加载管理员列表。
投稿功能增强 (支持引用)：
新增了 引用(回复)投稿 功能：现在可以回复别人的图片发送“语录投稿”进行保存。
解析逻辑修复：针对不同协议端（OneBot V11）返回的引用消息格式（JSON数组或CQ码字符串）进行了兼容处理，增加了正则匹配逻辑，解决了无法识别引用图片的问题。
图片下载逻辑优化：
重构了 download_image 方法。
增加容错机制：如果无法从本地缓存读取（例如引用消息的情况），会自动尝试通过 API 获取路径，最后尝试通过 URL 下载。
新增主动触发指令：
新增了 /语录 或 语录 指令，允许群友不通过“戳一戳”也能主动请求一张随机语录。

## 版本更新v1.5 (WebUI 管理界面 + 自定义概率)
应 [#4](https://github.com/litsum/astrbot_plugin_quote_collocter/issues/4) (建议添加配置选项来自定义概率) 和 [#5](https://github.com/litsum/astrbot_plugin_quote_collocter/issues/5) (可不可以加一个删除语录和列出语录的功能) 的需求，本次更新：

- 新增 `戳戳概率` QQ 指令（仅管理员）：0.0~1.0 之间的小数，控制 bot 被戳时发送语录的概率（默认 0.85，向后兼容旧行为）
- 新增 WebUI 管理页面，方便查看、删除错投的语录

打开 AstrBot Dashboard，左侧菜单 插件 -> 语录管理 即可进入。

WebUI 主要功能（已回应 issue #5 提到的删除/列出诉求，并扩展了一些常用管理能力）：

- 列出所有有语录的群：侧边栏按图片数量倒序展示
- 列出某群的所有语录：分页网格视图，支持文件名搜索
- 删除语录：单张 / 批量多选删除（用于清理错投）
- 移动语录：把语录从当前群搬到另一个群
- 上传语录：拖拽图片直接上传到指定群
- 修改群设置：在线调整投稿权限 (0/1/2)、戳戳冷却秒数、戳戳发送语录的概率
- 浅色/深色主题，中英双语

实现要点：
- 前端：React 18 + Ant Design 5 + TanStack Query + Zustand，构建产物已预编译到 `pages/quote-gallery/`，用户无需 Node 环境
- 后端：通过 AstrBot `register_web_api` 注册到 `/api/plug/quote_collocter/...`，前端通过 Dashboard Bridge (`window.AstrBotPluginPage`) 调用
- 缩略图：可选依赖 Pillow，未安装时回退到原图
- 概率改动向后兼容：未配置 `poke_probability` 的群仍使用原来的 0.85 默认值

## 注意事项

## 可选依赖 (WebUI)

## WebUI 开发 (可选)
如果你想修改 WebUI 前端源码:
```bash
cd webui
npm install
npm run build
# 产物会自动输出到 ../pages/quote-gallery/
```
重新构建后需要重启 AstrBot 让 dashboard 重新加载页面资源。
